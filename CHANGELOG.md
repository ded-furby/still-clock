# Changelog

## 1.0.1 — 2026-10-15

- Keep live wallpaper above the system desktop picture and below Finder icons; restore it after wake, unlock, and Space changes.
- Prevent hiding or closing the settings window from hiding the desktop clock.
- Add independent display layouts, including a right-aligned dial with a flowing directional animation for a monitor on your left.
- Preserve existing dial settings when upgrading and respect Reduce Motion in the companion animation.
- Confirm actual live wallpaper and protected screen saver operation on both iMac and Lenovo displays.

## 1.0.0 — 2026-10-14

- Native live desktop wallpaper and standalone macOS screen saver.
- Eight dial palettes, luminous night mode, and automatic system appearance.
- Sweep, mechanical, and quartz movement; local and selected world time zones.
- Size, numerals, second hand, date, and gentle position drift controls.
- Menu-bar app, screen saver installer, and optional launch at login.
- Universal packaging, original generated artwork, local checks, and CI.

Initial distribution is ad-hoc signed, not notarized. See the setup guide for the distinction between a protected screen saver and Apple’s login screen.
